# Kubo - Family Organizer
Kubo is a local-first family household app whose AI runs on the phone or laptop, so a household's medicine, money, and schedules stay private and keep working when the internet doesn't.
## Key Features
Medicine tracker with Local AI scanning.
Shared calendar for events and reminders.
Shared grocery list and debt tracker.
Family Circle System that includes all family members
We want a modern design, light mode, and targets mobile devices instead of computer websites.
We want to target devices like iphone 13+

Functionality isnt needed, only ui interactions
